# Introduktion

ElOverblik er din indgang til et klart overblik over dit elforbrug, dit klimaaftryk og muligheder for API integrationer. På denne side har vi samlet brugervejledninger, der hjælper dig med at komme i gang – uanset om du vil tilgå data via vores API eller oprette fuldmagter. Formålet er at gøre det nemt for dig at bruge ElOverblik.

Du kan blandt andet læse om:

- [Brug af API](https://docs.eloverblik.dk/docs/guides/api): Information omkring brug af API
- [Fuldmagter](https://docs.eloverblik.dk/docs/guides/power-of-attorneys): Information omkring fuldmagter
- [Datadeling](https://docs.eloverblik.dk/docs/guides/data-sharing): Information omkring datadeling

Andre sider, du måske finder brugbare:

- [Log ind på ElOverblik](https://eloverblik.dk/): ElOverblik \| Forside
- [Læs om DataHub](https://energinet.dk/data-om-energi/datahub/): Få indsigt i, hvad vi tilbyder, og hvordan det fungerer.
- [Klimaaftryk](https://docs.eloverblik.dk/docs/climate-footprint/introduction): Lær mere omkring klimaaftryk og hvordan de udledes fra dit elforbrug.
- [Bliv tredjepart](https://eloverblik.dk/help#poa-for-third-party-apply): Se, hvordan du ansøger, i vores FAQ på ElOverblik \| Hjælp.
- [FAQ](https://eloverblik.dk/help): Har du spørgsmål, kan du finde svarene i vores FAQ.
